# Expense Tracker

## About the Project
An interactive Expense Tracker web application built using HTML, CSS, and JavaScript to manage income and expenses.

## Features
- Add income and expenses
- Track total income
- Track total expenses
- Automatically calculate available balance
- Save transactions using browser Local Storage

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
